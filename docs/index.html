Vid Archiver GUI

A graphical front end for yt-dlp, inspired by the yt-dlg oleksis fork. It's designed to be dead simple to use and to fix the minor things that annoyed me with other GUIs. The big addition is folder rules, which pick the destination folder automatically based on where a video comes from.

This was an experiment with Claude Opus 5.5 and it went fairly well. Since I reviewed and edited the code I do not consider this to be "vibe coded" but almost all the code in one way or another was written by Claude. I consider it ready to use.

Windows, macOS and Linux · Free and open source (Apache 2.0)

What it does

yt-dlp without the command line

Paste links, pick a preset and click Start. The app builds the yt-dlp command and shows its progress.

Presets are yt-dlp options

Paste the command you already use. Any yt-dlp option works.

Folder rules

Pick the save folder automatically from the info yt-dlp reports for each link. More below.

A queue

Add lots of links and run several downloads side by side.

Automatic setup

Installs yt-dlp on first run, and FFmpeg and deno with one click, verified against the publishers' checksums.

Updates and rollback

Checks for yt-dlp updates daily. If a new release breaks something, roll back with one click.

Pick your yt-dlp build

Stable, nightly, master or your own fork, chosen per preset. youtube-dl works too.

Readable errors

Reads yt-dlp's error output, retries network problems, and tells you what went wrong.

Private

No accounts, analytics or telemetry. Everything stays on your computer.

The README covers everything in more detail.

Folder rules

Rules are checked top to bottom and the first match decides. If nothing matches, the fallback folder is used.

  • Match on site, domain, channel, playlist, title or URL (Equals, Contains, StartsWith or Regex)
  • Use tokens like {site}, {channel} or any yt-dlp field in the folder path, with fallbacks like {channel|uploader|"Unknown"}
  • Test a URL shows which folder a link would get
  • Set a folder by hand, then click Remember to turn it into a rule

Download

Get the latest build from Releases. Builds are self-contained, so you don't need .NET installed.

Windows 10/11

The easiest way is the Microsoft Store: it's signed and updates itself. Or get the standalone .exe in a .zip from Releases. That one isn't code-signed, so SmartScreen may warn on first launch: choose More info → Run anyway.

Linux x64/arm64

An .AppImage: make it executable and run it. Or a .tar.gz: unpack it and run ./install.sh (--remove uninstalls).

macOS 14+

Not notarized, so macOS blocks it the first time: open it once, then choose System Settings → Privacy & Security → Open Anyway (on macOS 14, right-click the app and choose Open).
